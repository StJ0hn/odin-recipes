# Odin Recipes

## Description
A simple multi-page website built with HTML to practice core web fundamentals,
listing recipes with their ingredients and preparation steps.

## Overview
This project is part of The Odin Project's Foundations course. The goal was to
build a small static site without CSS, focusing purely on HTML structure and semantics.

## Topics
- Text Formatting
- Links
- Images
- Lists

## Learning Objectives
- Practice writing semantic HTML (headings, lists, images)
- Structure a multi-page site with internal navigation
- Use ordered and unordered lists appropriately
